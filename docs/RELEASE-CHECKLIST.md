# BioNexa Release Checklist

## Application
- [ ] Navigation works.
- [ ] Every feature page displays correctly.
- [ ] No unresolved JavaScript imports.
- [ ] Production build succeeds.
- [ ] Layout works on Android screens.

## AI services
- [ ] Gemini model identifier verified.
- [ ] Worker POST requests work.
- [ ] AI Tutor responds correctly.
- [ ] AI quizzes generate valid questions.
- [ ] AI flashcards generate valid cards.
- [ ] Invalid AI responses are handled.
- [ ] Worker abuse protection enabled.
- [ ] API key remains a Cloudflare secret.

## Learning features
- [ ] Subject library works.
- [ ] Calculators return correct results.
- [ ] Formula search works.
- [ ] Practice results are saved.
- [ ] Weak-topic recommendations work.
- [ ] Notes persist after reload.
- [ ] Planner tasks persist after reload.
- [ ] Flashcard decks persist after reload.

## Offline behaviour
- [ ] Saved notes work offline.
- [ ] Saved flashcards work offline.
- [ ] Practice history works offline.
- [ ] AI features explain when internet is required.

## Android
- [ ] GitHub Actions creates Android project.
- [ ] Capacitor sync succeeds.
- [ ] Android build succeeds.
- [ ] APK artifact is generated.
- [ ] APK installs on the phone.
- [ ] Microphone permission works.
- [ ] App storage works on device.

## Branding
- [ ] App icon created.
- [ ] Splash screen configured.
- [ ] In-app logo added.
- [ ] App name displays correctly.

## Before public release
- [ ] Privacy notice prepared.
- [ ] App version and author details added.
- [ ] Worker abuse protection enabled.
- [ ] No API keys committed to GitHub.
- [ ] Test on a real Android device.
