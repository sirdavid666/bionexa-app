
# BioNexa

**Your Biomedical Engineering Academic Companion.**

BioNexa is an academic learning and productivity application
designed to support Biomedical Engineering students.

## Main Features

- AI-powered academic tutor
- Biomedical Engineering learning library
- Engineering calculators
- Formula library
- Lecture recording and transcription
- Personal notes
- Quizzes and flashcards
- Study planner and timetable
- Academic progress tracking
- Offline learning resources
- Android and Windows support

## Technology

- HTML
- CSS
- JavaScript
- Vite
- Capacitor
- Gemini API
- Cloudflare Workers

## Development

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build the application:

```bash
npm run build
```

## Android

The Android application uses Capacitor.

After building the web application:

```bash
npx cap add android
npx cap sync android
```

## AI Security

The Gemini API key must remain in Cloudflare Worker
secrets. Never place it in the application source code.
